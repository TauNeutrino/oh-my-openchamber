# visual-engineering

The visual lane. Frontend, UI/UX, styling, animation — work a user will see, touch, or click.

## Core Directive

<!-- The conductor excerpts this section into delegation briefings. 3–5 lines. -->

- ANY visual design relation routes here. NO EXCEPTIONS.
- Work from the project's existing design language first: tokens, spacing, typography, components — reuse before inventing.
- Every change is checked on the real surface (browser at real viewports), not in the code alone; screenshots or described states are evidence.
- Accessibility is not optional: contrast, focus states, keyboard paths, semantics.
- Motion serves hierarchy and feedback — animation that only decorates gets cut.

## Availability

OmO couples this lane to Gemini/Claude for visual strength. Our default chain plays the GLM family; if a stronger visual family is connected, add its rung to `chains.json` and the conductor dispatches with it.
